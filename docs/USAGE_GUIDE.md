# 使用指南

## 启动后先做什么

1. 打开左侧“设置”
2. 确认 `Base URL`、`API Key`、主模型是否正确
3. 若要扩充参考史料库，可另开终端执行：

```bash
cd /path/to/mingshi-reader-ai
npm --prefix backend run import:sources -- --slugs guoque,mingshi-jishi-benmo,mingji-beilue,da-ming-hui-dian,ming-shi-lu --max-pages 3
```

4. 回到“目录”，点击任意条目进入正文

## 日常阅读流程

### 翻页与进度

- 页面顶部使用“上一页 / 下一页”
- 底部进度条可快速跳转
- 当前章节名与阅读进度会同步显示

### 目录

- 左侧切到“目录”
- 直接点击条目跳转
- 当前版本已支持目录跳转与进度条联动

### 搜索

- 左侧切到“搜索”
- 输入人名、地名、制度名、事件名
- `本地模糊检索`：优先本地速度与稳定性
- `AI 意图检索`：适合“我想找朱元璋早年经历”这类模糊描述

### 选段辅助

在正文里选中一段文字后，顶部悬浮工具栏和右侧阅读助理都能直接执行：

- 高亮
- 下划线
- 记笔记
- 翻译
- 读音
- 解释
- 百科
- 史料比对
- 朗读

### 划词百科

适合查：

- 官职，如 `左都御史`
- 皇帝、年号，如 `弘治`
- 地名，如 `应天府`
- 人物，如 `张居正`

工作方式：

1. 先匹配本地 JSON 资料
2. 再调用 AI 把资料整理成适合阅读的短说明

### 史料交叉比对

适合精读时使用。

操作：

1. 在正文中选中一段《明史》原文
2. 点击“史料比对”
3. 系统会自动：
   - 提取关键词
   - 检索 SQLite 参考史料库
   - 生成 Markdown 考证报告

报告包含：

- 选段摘要
- 时间线对齐表
- 异同点
- 可考结论
- 参考史料

### 时间轴

- 右侧助理顶部点击“时间轴”
- 会弹出明代皇帝时间轴
- 当前章节若能匹配到庙号 / 年号，会自动高亮对应时期
- 面板下方带两京十三省交互式示意图

### 问答

右侧“直接提问”支持：

- 问这一段在说什么
- 问制度背景
- 问和前文的关系
- 问人物、时间、事件逻辑

### 笔记

- 在正文中选段后点击“记笔记”
- 笔记会自动保存
- 左侧“笔记”里可统一查看和回跳原文

### 书签

- 顶部点击“书签”
- 左侧“书签”中可回到对应位置

### 人物编年

- 左侧切到“人物”
- 输入人物名
- 点“本地整理”可快速汇总原文出现片段
- 点“AI 编年”可生成更完整的时间线摘要

### 年号对照

- 设置页可开关“自动标注明代年号与公元对照”
- 开启后，正文中的年号会带悬浮信息

### 自定义操作

- 设置页里填写：
  - 名称
  - System Prompt
  - User Template
- 模板中可使用：
  - `{{selection}}`
  - `{{context}}`
  - `{{question}}`
- 保存后会出现在右侧阅读助理和选段快捷操作中

### 朗读

- 点击顶部“朗读”或选段工具栏“朗读”
- 优先调用 AI TTS
- 如果接口失败，会自动退回浏览器朗读

## 推荐使用方式

- 通读时：目录 + 进度条 + 书签
- 精读时：选段解释 + 百科 + 史料比对 + 记笔记
- 查制度时：百科 + 《大明会典》参考库
- 做课程 / 论文准备时：史料比对 + 考点提炼 + 白话改写

## 常见问题

### AI 功能响应慢

当前已实现模型自动回退。若首选模型超时，系统会尝试备用模型。

### 史料比对命中太少

说明 starter corpus 覆盖还不够。可重新执行：

```bash
cd /path/to/mingshi-reader-ai
npm --prefix backend run import:sources -- --slugs guoque,mingshi-jishi-benmo,mingji-beilue,da-ming-hui-dian,ming-shi-lu --max-pages 5
```

### 正文打开较慢

首次加载会解析 EPUB 并初始化 SQLite 底库，之后会快很多。

### 朗读失败

若 AI TTS 平台不支持当前模型，前端会自动改用浏览器语音。
