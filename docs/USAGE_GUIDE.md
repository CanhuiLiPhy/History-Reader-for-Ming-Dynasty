# 明史阅读器 v1.0.3 使用教程

适用版本：**v1.0.3**（macOS arm64 dmg / Windows 便携版 zip / 源码运行）
更新日期：2026-05-04

---

## 一、安装

### A. macOS（推荐 dmg）

1. 下载 `明史阅读器-1.0.3-arm64.dmg`（约 912 MB，仅 Apple Silicon）
2. 双击 → 拖 **「明史阅读器.app」** 到 **「应用程序」** 文件夹
3. 启动栏 / 启动台找到「明史阅读器」打开
4. 第一次启动若 macOS 提示 *"无法打开，因为开发者无法验证"*：**系统设置 → 隐私与安全性 → 仍要打开**

### B. Windows（便携版 zip）

1. 下载 `明史阅读器-1.0.3-win.zip`（约 720 MB）
2. **右键 → 全部解压**（路径不要太长，不带特殊字符；建议 `D:\明史阅读器\`）
3. 双击解压目录里的 **`明史阅读器.exe`**
4. SmartScreen 蓝屏：**「更多信息」 → 「仍要运行」**
5. 黄色启动屏 *"正在启动后端服务"* — 等 10–30 秒主窗口自动开

> **注意：**不要单独把 `明史阅读器.exe` 拷到别处，它依赖同目录所有文件。

### C. 源码运行（开发者）

```bash
git clone https://github.com/CanhuiLiPhy/Reader-Mingshi.git
cd Reader-Mingshi
npm --prefix backend install --omit=dev
npm --prefix frontend install
cp backend/.env.example backend/.env   # 填 AI_API_KEY
bash start.sh                          # macOS / Linux
```

## 二、配置 AI API Key（首次必做）

### 1. 设置入口

主界面右上角**齿轮图标** + 版本徽章 `v1.0.3` → 点齿轮 → 弹出右侧「设置」面板。

### 2. 自定义 API 配置

设置面板底部 → 「自定义 API 配置」 → 居中模态弹窗。

### 3. 用预设供应商一键填充（v0.4.1+）

弹窗顶部「**预设供应商**」下拉，9 选 1：

| 供应商 | 适用场景 |
|---|---|
| 百炼（阿里云 DashScope） | DeepSeek / Kimi / Qwen 系列，国内速度快 |
| 火山引擎 | 豆包 / GLM 系列 |
| DeepSeek | 直连 deepseek-chat |
| Kimi (Moonshot) | 长上下文 |
| Anthropic | Claude 系列 |
| Gemini | Google |
| OpenAI | GPT 系列 |
| OpenRouter | 多模型聚合 |
| MiniMax | abab 系列 |

选完会自动填 Base URL、推荐主模型、推荐小模型、TTS 配置。

### 4. 填 API Key

「**API Key**」框（密码框，显示为 `••••`）粘贴你从供应商控制台拿到的 key（形如 `sk-xxxxxxxx`）。

百炼示例：浏览器开 https://bailian.console.aliyun.com/ → 登录阿里云 → 左侧「API-KEY」→ 创建 → 复制。

### 5. （可选）TTS API Key（v0.4.1 起支持独立）

TTS 朗读如果走主供应商，**TTS API Key 留空**（自动继承主 key）。如果想 TTS 走另一家（例如 TTS 用百炼，主模型用 OpenAI），填到「TTS API Key」框。

### 6. （可选）多供应商 / 自定义模型

弹窗中下部「自定义供应商（可选）」可加任意数量额外供应商：
1. 点「+ 添加供应商」 → 填 URL + Key + 备注名
2. 输入模型名 → 「+ 主模型」/「+ 小模型」 自动加进对应池

特定模型走指定供应商：把模型名写到该供应商的「模型范围」列表里，调用时优先用它的 URL+Key。

### 7. 保存

直接关闭弹窗 — **填完即生效，无需重启**。

### 8. 验证

正文里随便选几个字 → 弹出工具栏点「**现代文**」 → 几秒后右栏出现 AI 翻译，配置成功。

## 五、选段操作

正文中**拖拽鼠标选中**任意文字 → 浮出工具栏：

### 标注（v1.0.3 起支持跨段）

- **3 色高亮**：金笺（黄）/ 青玉（绿）/ 绛砂（红）
- **下划线**：正红 2 px 实线
- **圈点**：古文勾画法（红色字下圆点）
- **删除勾画**：选到已标记的段时显示

> v1.0.3 起，DB-reader（检索类书目）的勾画支持**跨段落**（cfi 加 `m` 标记），不再提示「跨段勾画暂不支持」。

### AI 操作

- **现代文** — 文言译白话
- **读音** — 标音
- **解释** — 释义
- **百科** — 词典 / 人物 / 制度 / 年号 / 历史地名（含百度百科入口）
- **史料比对** — 跨书检索（自动排除当前阅读的本书）
- **AI 句读** — 给古文加现代标点 + 在原文上**直接叠红圆点**（v1.0.3）
- **朗读** — TTS 读出选段（百炼 qwen3-tts 多音色）
- **识别日期** — 解析年/月/干支日，结合前文给公历+农历

### 笔记 / 书签

- **笔记** — 选段 + 自由文本笔记。可在保存对话框里**勾选「显示在历史时间线」**（v1.0.1）+ 设手工日期 / 重要度 / 类别 / 显示标题
- **书签** — 给当前位置命名 + 一键回跳

### 「保留」累积模式（v1.0.3 新增，跨页跨章选段方案）

右栏「当前选段」卡片标题栏右侧有 **保留** 勾选开关 + **清空** 按钮。

**默认关**：每次新选段替换旧选段 — 老行为不变。

**开启「保留」时**：
- 新选段不清空旧选段，而是**追加**到累积区
- 卡片 body 显示已 pin 段（灰色边竖线 #1 #2 …）+ 最新段（红色边竖线，标「最新」）
- AI 句读 / 现代文 / 解释 / 史料比对 / 百科 / 笔记 / 勾画 等动作**对累积后的整段生效**
- 勾画 / 笔记保存时**逐段独立保存**（每段一条 highlight / note，note 共享同一文本）
- AI 句读的红圆点会**叠到所有可见段**（已离开当前章节的段静默跳过）

**清理累积区**：
- 关掉「保留」开关 → 立即清空
- 点「清空」按钮 → 清空
- AI / 笔记 / 勾画完成后**不自动清空**（buffer 跨多次操作保留）

> 用途：跨页选某段引文 + 后文论述拼到一起做译白；或跨章节累积同主题段做集中比对。

### AI 句读特殊行为（v1.0.3）

- 不弹出「补充说明」对话框（与 现代文 / 读音 同列，机械任务）
- 默认走**小模型**（更快更省，质量与大模型持平）
- 结果除右栏渲染外，**直接叠红圆点到原文**：
  - **读号**（，、；：）= 实心红圆
  - **句号**（。！？）= 空心红圆
- 圆点叠加是瞬态的：下次选段 / 切章节 / 切书 / 再次句读 都自动清掉，不入笔记

按 `ESC` 或点选段外任何地方关闭浮动工具栏。

## 六、资料检索（左栏「资料」面板）

### 1. 全文搜索

- 混合搜索：子串匹配
- AI 引导：先让 AI 提取关键词再搜
- 范围：当前书 / 全部 22 部资料库

### 2. 人物编年（v1.0.1 重构）

输入人名，两种入口：

**本地整理** — 跨书全文检索 + 时间排序（秒回）

**AI 编年** — 命中**传记索引**（v1.0.1 新增 776 历史人物，从明史 / 石匮书后集 / 东林列传 / 罪惟录 抽出）时，直接传完整列传切片给 AI；未命中走旧的关键词检索

**百度百科**（v1.0.1） — 内嵌 iframe，不出软件直接看百科

### 3. 历史时间线（资料 → 历史时间线，v1.0 新增）

#### 数据源

《**中国历史大事年表 古代及中世纪史部分**》（吉林师范大学历史系 中国古代及中世纪史教研室 编）的 OCR 扫描版。原始版权归编者所有。

#### 三种范围模式

| 模式 | 用法 | 适合 |
|---|---|---|
| center | 中心年份 ± 半径（5–140 年） | "1572 张居正前后十年" |
| range | 起止年份显式给定 | "1573–1620 万历朝" |
| reign | 17 个明代年号 quick-pick | 一键加载某年号全期 |

#### 11 类事件分类

皇室 / 政争 / 制度 / 军事 / 民变 / 外交 / 经济 / 灾异 / 文化 / 人物 / 其他 — 每类一种颜色。

后端两段式分类器：先按关键词选 category，再按事件强度打 scale 1–5（1=边角，5=朝代级）。元末（1368 前）单独路径，避免「朱元璋」在元末被误判为后期太祖。

#### 详细级别（scale 过滤）

下拉 1–5。范围跨度自动调阈值：跨 200 年起 ≥4，跨 100 年起 ≥3，跨 40 年起 ≥2 — 长跨度自动隐藏点状事件。

#### 客户端关键词搜索

右上「关键词搜索」框 — 在描述 / 年号 / 类别 / 笔记文本中匹配，不重新请求后端。

#### 笔记接入（v1.0.1 起）

笔记编辑对话框打开「显示在历史时间线」开关后，该笔记会以 **橙色圆点** 与官修事件混排：

- 默认按 `historicalYear`（自动识别的年份）定位
- 可手工覆盖年/月/日
- 设重要度 1–5（控制圆点大小）+ 类别（默认「我的笔记」）+ 显示标题
- **点笔记 → 跳回原书原 cfi**

### 4. 皇帝世系图

19 帝（含建文）家谱树。点节点 → 弹出该帝详细信息。

### 5. 年号 互转 公元换算

### 6. 职官检索

## 七、AI 问答与自定义动作

### 自由问答（右栏底部）

- 不选段问：「明朝初期的卫所制度是怎么运作的？」
- 结合选段问：先选段 → 在输入框追加问题 → AI 把选段当上下文

### 自定义 AI 操作

设置 → 「自定义 AI 操作」 → 写 system prompt + user template → 加完后出现在选段工具栏。

例：「人物关系梳理」/「分段串讲」/「写白话故事」。

### 模型选择策略（v1.0.3）

| 任务 | 默认模型 | 跳过补充弹窗 |
|---|---|---|
| AI 句读 | **小模型** | 是 |
| 读音标注 | **小模型** | 是 |
| 现代文翻译 | **小模型** | 是 |
| 解释 | 大模型 | 否 |
| 史料比对 | 大模型 | 否 |

## 八、日期识别（v1.0.1+ 大修）

选段中第一个日期成分（年 / 月 / 干支）配合**前文上下文**（含跨章节）算到日。

### 多级回溯算法

1. 从选段往前找完整年号（永乐元年八月二十八）
2. 没找到 → 再往前一段找
3. 仍没找到 → 翻到上一章末尾继续找（**跨章节兜底**，v1.0.1）

### 支持的年号

- 明朝全部 17 帝
- 元末 13 个年号（至元 / 天历 / 至顺 / ... / 至正）
- 清前期 6 个年号（顺治 ~ 道光）
- **吴**（朱元璋称帝前 1364–1367）
- 繁简兼容（永樂 / 隆慶 / 萬曆 / 崇禎 等）+ 闰/閏 兼容

### 实录干支纪年专属解析（v1.0.2）

太祖实录 卷之一 ~ 卷之二十一（覆盖 1328–1367 朱元璋称帝前期）走**独立路径** `resolveShiluSelectionDate`：
- 文本以「乙未春正月戊午」等干支纪年形式出现
- 60 年甲子周期 + 章节 → 年范围映射
- 卷 22 起进入洪武纪年走通用路径

### 农历←→公历换算

精确到日。例：「秋七月癸酉」自动追溯前文 `永乐元年` → 「永乐元年八月二十八（1403-09-14）」。

## 十、常见问题

### Q：双击 .exe 没反应 / 启动屏卡死

A：可能是 Windows Defender 隔离主 exe。打开「Windows 安全中心 → 病毒和威胁防护 → 排除项」，把整个解压目录加白名单。

### Q：界面是简体，怎么切回繁体？

A：右栏设置 → 页面外观 → 「界面字体转换」选「繁体」 → 立即生效。**反过来需要刷新页面**（按 F5），转换是单向的。

### Q：识别日期对不上？

A：检查前文是否有完整的「<年号><年>年」结构（如「永乐元年」）。识别器需要这个锚点。如果当前段缺失，识别器会**自动往前翻段甚至翻章节**找；如果整本书前面都没有（特殊版本断章），可手动加大选段范围把年号也包进去。

### Q：跨页选段勾画不上？

A：v1.0.3 引入「**保留**」开关（右栏「当前选段」卡片标题栏）。开启后第二段选完会接到第一段后面，再点勾画即可对所有累积段一起标记。也可用于句读 / 翻译 / 比对 等。

### Q：明实录的日期识别为什么不一样？

A：太祖实录 卷 1–21 用干支纪年（"乙未春正月戊午"），卷 22 起改用洪武纪年。识别器自动判断章节走专属解析路径。

### Q：AI 句读结果只在右栏显示，正文没标？

A：v1.0.3 起句读会**直接叠红圆点到原文**（读号实心 / 句号空心）。如未生效，可能是选段已经被切章节，重新选段再试。

### Q：怎么把笔记显示到历史时间线？

A：编辑该笔记 → 弹出对话框里勾选「显示在历史时间线」 → 可手工填年月日 / 选重要度 / 选类别 / 给标题。打开「资料 → 历史时间线」即可看到笔记与官修事件混排。

### Q：默认是火山，想切回百炼？

A：API 配置弹窗 → 顶部「预设供应商」选「百炼 (阿里云 DashScope)」 → 自动覆盖。

### Q：方正字体可以商用吗？

A：**不行**。方正系列三款（永乐大典楷体 / 瘦金 / 礼器碑）仅授权个人非商用使用。商用需另向方正字库取得授权。
