# 明史阅读器 v0.4.1 使用教程

适用版本：**v0.4.1**（Windows 便携版）

---

## 一、安装（Windows 便携版）

> 便携版无需走任何安装向导，**解压即用**，不写注册表。

### 1. 解压压缩包

1. 把 `明史阅读器-0.4.1-win.zip`（约 720 MB）下载好
2. **右键 → 全部解压**（或用 7-Zip / Bandizip）
3. 解压目标位置建议：`D:\明史阅读器\`，路径不要太长，不带特殊字符
4. 解压后得到一个 `明史阅读器-0.4.1-win` 目录，约 1.3 GB

### 2. 启动

进入解压目录，双击 **`明史阅读器.exe`**（约 195 MB）。

#### 第一次启动可能弹窗

- **Windows SmartScreen 蓝屏警告**：点 **「更多信息」 → 「仍要运行」**
- **黄色启动屏**「正在启动后端服务…」：等约 10–30 秒，主窗口会自动打开

### 3. 桌面快捷方式（可选）

右键 `明史阅读器.exe` → **「发送到」 → 「桌面快捷方式」**。

> ⚠️ 不要单独把 `明史阅读器.exe` 拷到别处 — 它依赖同目录下的所有文件。

## 二、配置百炼 API Key（首次必做）

### 1. 找到设置入口

主界面右上角有齿轮图标 ⚙ + 版本徽章 `v0.4.1`。**点齿轮** → 弹出右侧「设置」面板。

### 2. 滚到「自定义 API 配置」按钮

在「设置」面板底部，点 **「自定义 API 配置」**。弹出居中模态弹窗。

### 3. 用预设供应商一键填充

弹窗顶部第一项是 **「预设供应商」下拉**。选 **「百炼 (阿里云 DashScope)」**。

填好的字段：
- **OpenAI 兼容 Base URL**：`https://dashscope.aliyuncs.com/compatible-mode/v1`
- **主模型列表**：`deepseek-v4-pro`、`kimi-k2.6`、`qwen3.6-max-preview`、`MiniMax-M2.5`、`qwen3.5-plus-2026-04-20`
- **小模型列表**：`deepseek-v4-flash`、`qwen3.6-flash`、`qwen3.6-27b`
- **TTS Base URL**：自动同主 URL
- **TTS 模型**：`qwen3-tts-flash`

### 4. 填 API Key

在 **「API Key」** 框（密码框，输入显示为 `••••`）粘贴你从百炼控制台拿到的 key（形如 `sk-xxxxxxxx`）。

如何拿百炼 API Key：
1. 浏览器开 https://bailian.console.aliyun.com/
2. 登录阿里云账号 → 左侧「API-KEY」
3. 点「创建我的 API-KEY」 → 复制
4. 粘贴到弹窗里的 API Key 框

### 5. （可选）TTS API Key

TTS 朗读如果走百炼，**TTS API Key 留空**（自动继承主 API Key）。其他 TTS 字段都已自动填好，不用动。

### 6. （可选）多供应商

想给特定模型用不同的 key（例如主模型百炼，但某个模型走火山）：
1. 滚到弹窗中下部「自定义供应商（可选）」
2. 点「+ 添加供应商」 → 填 Base URL + API Key
3. 输入模型名 → 点「+ 主模型」或「+ 小模型」自动加进对应列表

### 7. 保存

直接关闭弹窗 — **填完即生效，无需重启**。

### 8. 验证

随便选一段正文（拖拽鼠标选中几个字），弹出工具栏点 **「现代文」** —— 几秒后右栏出现 AI 翻译，说明配置成功。

## 三、内置功能详解

### A. 多书阅读（22 部）

#### 切换书目

左侧栏顶部 **「切书」下拉**列出全部 22 本：
- **EPUB 原典**（12 部）：明史 / 国榷 / 明通鉴 / 崇祯长编 / 罪惟录 / 三朝辽事实录 / 大明律 / 大明会典 / 国朝献征录 / 明季北略 / 天下郡国利病书 / 明史纪事本末
- **检索类**（10 部）：明实录（14 部子实录共 16 万段）/ 皇明经世文编 / 廿二史札记 / 万历野获编 / 明季南略 / 东林列传 / 菽园杂记 / 石匮书 / 国朝典汇 / 明史四库全书本

每本独立保留阅读位置。

#### 翻页

- 点屏幕**左 / 右边缘**翻页
- 底部进度条**拖动**跳页
- 章节切换：左栏「目录」面板 / 顶栏「章节滑块」

#### 阅读体验设置（右栏「设置」面板顶部）

- **正文字体转换**：保留原文 / 转换为繁体（默认繁体）
- **界面字体转换**：简体 / 繁体（默认繁体）
- **虚拟翻页分栏**：单栏 / 双栏对开
- **阅读主题**：默认（米白）/ 古籍米黄 / 夜间 / 护眼绿
- **正文字体**：宋体 / 仿宋 / 楷书 / 隶书 / 瘦金体
- **字号**：13–28 px
- **字色**：自定义或跟随主题
- **日期显示**：仅农历 / 仅公历 / 公历+农历（默认仅农历）
- **气泡显示在位皇帝**：可选（默认关闭）

### B. 选段操作

在正文中**拖拽鼠标选中**任意文字，会浮出工具栏：

- **3 色高亮**：金笺（黄）/ 青玉（绿）/ 绛砂（红）
- **下划线**：正红 2 px 实线
- **圈点**：古文勾画法（红色字下圆点）
- **标记**：把选好的样式应用到选段
- **删除勾画**：选到已标记的段时显示
- **笔记**：保存选段 + 自由文本笔记
- **读音**：AI 标注读音
- **百科**：查词典 / 人物 / 制度 / 年号 / 历史地名
- **史料比对**：跨书检索相关段（自动排除当前阅读的本书）
- **现代文**：把文言文翻译成白话
- **朗读**：AI TTS 读出选段
- **识别日期**：解析选段中的年/月/干支日，结合前文给出公历 + 农历精确日期

按 ESC 或点选段外任何地方关闭工具栏。

---

### C. 资料检索（左栏「资料」面板）

#### 1. 全文搜索

左栏顶部搜索框：
- **混合搜索**：子串匹配
- **AI 引导**：先让 AI 提取关键词再搜
- 范围：当前书 / 22 部资料库
- 结果：章节标题 + 高亮段落 + 跳转链接

#### 2. 人物编年

输入人名，两个按钮：
- **本地整理**：纯本地全文检索 + 时间排序（秒回）
- **AI 编年**：AI 整理成连贯小传（30–60 秒）

输出：总览 + 时间倒序条目（年号 / 事件 / 原文片段）。

#### 3. 皇帝世系图

19 帝（含建文）家谱树。点节点弹出该帝详细信息（年号、在位、尊号、生卒、关键事件）。

#### 4. 年号 ⇄ 公元换算

输入「弘治三年」 → 公元 1490；输入「公元 1490」/「1490」 → 弘治三年。

#### 5. 职官检索

12 院司 + 644 具体官职 + 3502 历任年表 + 979 藩王 + 55 套字辈命名诗。
- 按官署 / 品级 / 朝代 / 人名筛选
- 历任表可按公元年份 / 年号 / 人名搜

#### 6. 古今地名地图

- 输入古地名 → 本地数据库匹配
- 未命中走 AI 推断 → 经纬度坐标
- 中央研究院历史地名查询：嵌入页面 + **「新窗口打开」**按钮（嵌入版会被中研院反第三方 cookie 阻挡，必须用新窗口）

---

### D. AI 问答（右栏底部）

#### 选段触发

工具栏的 现代文 / 解释 / 读音 / 史料比对 / 朗读 / 识别日期 / 自定义动作 都走 AI。

#### 自由提问

右栏底部输入框 + **「开始问答」** 按钮：
- **不选段问**：「明朝初期的卫所制度是怎么运作的？」 → AI 调资料库 + 网搜
- **结合选段问**：先选段 → 在输入框追加问题 → AI 把选段当上下文
- **闲聊也行**：「你好」「现在几点」 → 自动判断不需要查资料库，简明直答

整个流程总耗时约 30–90 秒。

#### 自定义 AI 操作

设置面板 → 「自定义 AI 操作」 → 自己写 system prompt + user template → 加完后会出现在选段工具栏。例如：
- 「人物关系梳理」
- 「分段串讲」
- 「写白话故事」

---

### E. 批注 / 笔记 / 书签

- 全部本地保存（Win 上是 `%APPDATA%\明史阅读器\`）
- 切书 / 重启 / 关闭都会保留
- 「笔记」面板可统一查看 + 编辑 + **导出 Markdown**
- 「书签」面板可命名书签 + 一键跳转

## 四、常见问题

### Q：双击 .exe 没反应 / 启动屏卡死

A：可能是 Windows Defender 在隔离主 exe。打开「Windows 安全中心 → 病毒和威胁防护 → 排除项」，把整个解压目录加白名单。

### Q：界面是简体，怎么切回繁体？

A：右栏设置 → 页面外观 → 「界面字体转换」选「繁体」 → 立即生效。**反过来（繁→简）需要刷新页面**（按 F5），因为转换是单向的。

### Q：识别日期对不上？

A：检查前文上下文是否有完整的「<朝代名><年>年」结构（如「永乐元年」）。识别器需要这个锚点。如果前文没有，请加大选段范围把朝代年号也包进去。

### Q：检索类（如皇明经世文编、廿二史札记）的书无法标注？

A：v0.4.1 已支持单段内的高亮 / 下划线 / 圈点。**跨段选段还不支持**（会提示「跨段勾画暂不支持」）。

### Q：默认是火山，想切回百炼？

A：打开 API 配置弹窗 → 顶部「预设供应商」选「百炼 (阿里云 DashScope)」 → 自动覆盖回百炼。

## 五、数据隐私

- 所有阅读位置 / 笔记 / 高亮 / API Key 全部本地存储，**不上传任何服务器**
- AI 调用直接打到你填的 API 端点，中间无第三方
- 网页搜索走 DuckDuckGo（最佳-effort，失败不影响主流程）
- 中研院地名查询是嵌入第三方网页（仅参考）

当前：**v0.4.1**

1. 下载新版 zip
2. 解压到**新目录**（不要覆盖旧目录）
3. 启动新版后，所有本地数据自动从 `%APPDATA%\明史阅读器\` 继承
4. 旧目录可删可留
