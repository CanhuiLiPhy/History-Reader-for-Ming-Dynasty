# 明史 AI 阅读器 — v0.4 → v1.0.3 功能更新汇总

本文档汇总自 2026-04-30 v0.4 至 2026-05-04 v1.0.3 期间的所有功能性变更。
各版本独立细节见 [donotpack/progress.md](../donotpack/progress.md) 与
按发版日期组织的子文档（[0504.md](./0504.md) / [0505.md](./0505.md)）。

## 一、阅读体验

### 翻页与排版

- 检索类（TXT 来源）书目可读性大改
  - 翻页区域改为 host 同级元素，第 1 页之后点击边缘失效问题修复
  - 容器锁横滑，触摸板 / 滚轮误触不再翻页
  - 翻页稳定器：连点边缘自动 snap 到整数页边界
  - **锚点段落 reflow**：左右栏开合后 100% 回到原页（按 `data-paragraph-id` 找回新列偏移）
- DB-reader 支持高亮 / 下划线 / 圈点（基于段内字符偏移 cfi）
- **跨页（跨段落）勾画**（v1.0.3）：cfi 加 8 段 `m` 标记格式，渲染时按 [起始段, 结束段] 区间逐段切片包 span，原"跨段勾画暂不支持"限制解除
- `last-location` 改为 per-book key，防止一本书的 CFI 串到另一本书
- 底部进度条：默认收起，与左侧栏开合同步；点进度条直接 CFI 跳转，不再逐页翻动

### 字体与界面

- v0.4：界面字体简繁切换（独立于"正文字体转换"），新设置项「界面字体转换」(默认繁体)。OpenCC + MutationObserver 全 UI 即时转换
- v1.0.2：**8 款内置字体扩充**（汇文明朝 / 汇文仿宋 / 汇文正楷 / 京华老宋 / 霞鹜文楷 / 方正永乐大典楷体 / 方正瘦金 / 方正礼器碑）+ 系统宋体 / 系统仿宋两个回退栈，共 10 选项
- v1.0.2：**界面字体独立于正文字体**，两个独立下拉。默认：界面=汇文正楷，正文=汇文明朝
- v0.4：4 套主题铺到全局 UI（默认 / 古籍米黄 / 夜间 / 护眼绿）

### 读通鉴论显示修复

- v1.0：原 EPUB（Kindle 转套装 5 册 5.6 MB）spine 解析失败导致 reader 一直空白；换中华书局 1975 校点本（Calibre 转 843 KB），写一次性预处理脚本把单 spine 段塞多章节（`<p id="fileposNNN">`）的 Calibre 格式拆成 122 个独立 spine 段

## 二、AI 与检索

### AI 问答

- v0.4.1：**AI 问答更聪明**——闲聊 / 与明代无关问题不再硬扯检索结果
  - planner 阶段加 `needsLibraryLookup` 判断
  - 检索结果加相关性二次过滤
  - 选段无关时不展示选段附近段落作为「依据」

### AI 句读 / 读音 / 翻译（v1.0.3）

- **跳过补充 prompt 弹窗**：句读 / 读音 / 现代文翻译 三个机械任务直接执行
- **默认改用小模型**：这三项 quality 与大模型持平但更快更省
- **句读结果叠加正文**：右栏渲染之外，同步以红圆点直接叠加到原文上（瞬态，不写入笔记/勾画）
  - 标注规范：读号（，、；：）→ 实心红圆，句号（。！？）→ 空心红圆
  - 用 CSS 圆形避免不同 CJK 字体下字符渲染不一致

### 多供应商 API

- v0.4：**自定义供应商**（URL + Key + 模型组），可覆盖默认 key 给特定模型用别家服务；支持「+ 主模型 / + 小模型」分类添加
- v0.4.1：新增 **9 个预设供应商**下拉（百炼 / 火山 / DeepSeek / Kimi / Anthropic / Gemini / OpenAI / OpenRouter / MiniMax）—— 选完自动填 Base URL + 推荐模型名
- v0.4.1：**新增 TTS API Key 字段**（之前必须复用主 key）

### 数据质量大修（v1.0）

- **石匮书换源**：从 wikisource 爬取版（218 章 / 4299 段，OCR 噪声多）切换为「ctext 净本（卷一~卷四）+ shiku-shu OCR Pass 3 手工重写（卷五~卷十七）」组合版（17 章 / 565 段）
  - PaddleOCR-VL（Colab A100）+ MinerU 双路 OCR，Claude Sonnet 通读重写
- 详细工作记录见 [docs/0504.md](./0504.md)

## 三、笔记与勾画

- v0.4：**3 色高亮 + 下划线 + 古文圈点**（红色字下圆点）+ 笔记 + 书签（编辑、导出 Markdown）
- v1.0.3：跨段勾画支持（见 §一）
- v1.0.1：**笔记 ↔ 历史时间线集成**

  - 卡片一键切换；点条目跳回原文 cfi

## 四、历史 / 时间 / 工具

### 日期识别

- v0.3.1：**农历⇄公历精确换算**（选段中第一个日期成分配合前文上下文计算到日）。例：「秋七月癸酉」自动追溯前文 `<reign>(year)年`，得「永乐元年八月二十八（1403-09-14）」
- v0.4：年号识别支持永樂、隆慶、萬曆、崇禎、天啟、天順、正統 等繁体形式 + 闰/閏 兼容
- v0.4：**设置可控**：日期显示「仅农历 / 仅公历 / 公历+农历」(默认仅农历)；可选显示在位皇帝
- v1.0.1：**日期识别大修**——多级（日→月→年→reign）回溯 + 跨章节兜底；元 / 清 / 吴年号扩展
- v1.0.2：**明实录干支纪年专属解析**（仅 太祖实录 卷之一~卷之二十一，覆盖 1328-1367 朱元璋称帝前期）；卷 22 起进入洪武纪年走通用路径

### 历史时间线（资料 → 历史时间线，v1.0 新增）

- 数据源：《**中国历史大事年表 古代及中世纪史部分**》（吉林师范大学历史系，中国古代及中世纪史教研室 编）的 OCR 扫描版本，原始版权归编者所有
- 三种范围输入模式：center（中心年份±半径）/ range（起止）/ reign（17 个明代年号 quick-pick）
- 11 类两段式分类器（皇室 / 政争 / 制度 / 军事 / 民变 / 外交 / 经济 / 灾异 / 文化 / 人物 / 其他）+ scale 1–5 重要度
- 元末路径前置：朱元璋 / 陈友谅 / 徐寿辉 / 张士诚等称帝/称王 → 皇室 5；元末群雄 → 民变 / 军事
- 跨度自动调 minScale；多类别筛选 + 客户端关键词搜索
- 笔记按 `manualYear` / `historicalYear` 与官修事件混排，橙色区分；点笔记跳回原书原 cfi

### 人物编年（v1.0.1 重构）

- 新增**传记索引**：跨 明史 / 石匮书后集 / 东林列传 / 罪惟录 共 776 历史人物，按章节标题 + 首段名单提取
- AI 编年命中索引时直接传完整列传切片（不再只是 200 字关键词命中）
- **百度百科嵌入**：人物 panel 内 iframe 直接显示百科页

### 古今地名地图（v0.4.1）

- 加「**新窗口打开**」按钮——嵌入版会被中研院反第三方 cookie 强制跳回首页
- iframe sandbox 加 `allow-popups-to-escape-sandbox` / `allow-top-navigation-by-user-activation`

## 六、版权 / 数据声明

- **正文 / 古籍**：互联网公开资源（Wikisource / CText 等）+ 个人整理 + 基于公开资源的 OCR 处理
- **历史时间线数据**：《中国历史大事年表 古代及中世纪史部分》OCR 扫描，仅引用，原始版权归编者所有
- **字体**：内置 8 款字体许可不一。绝大多数为开源（霞鹜文楷 / 汇文系列 / 京华老宋）；方正系列（永乐大典楷体 / 瘦金 / 礼器碑）仅授权个人非商用使用，商用需另行向方正字库取得授权
- **AI**：第三方大语言模型 API 提供，回答仅供参考
- **总体**：本软件仅供个人学习研究使用，**不得用于商业用途**
